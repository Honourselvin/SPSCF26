# SPSCF26 Pharmacy Billing

Offline-first Windows pharmacy billing MVP built with Python, Tkinter and SQLite.

## Features
- Fast keyboard-first billing screen
- Medicine master with batch, expiry, MRP, purchase price, GST and stock
- Automatic stock deduction on completed sales
- Invoice history and printable invoice text export
- Customer name/phone and cash/credit payment tracking
- Low-stock and near-expiry dashboard alerts

## Run on Windows
1. Install Python 3.11+ from python.org.
2. Download/clone this repository.
3. Run `python main.py`.
4. The local database `pharmacy.db` is created automatically.

No third-party Python packages are required for the MVP.
